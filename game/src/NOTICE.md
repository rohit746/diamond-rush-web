# Not covered by this repository's license

The Java files in this directory are a decompilation of **Diamond Rush** (Gameloft, 2006; Nokia J2ME
build 1.1.6), renamed with `mappings/diamondrush.map` and hand-edited so that they compile and behave
exactly like the original bytecode. The code is Gameloft's and remains the property of its copyright
holder. It is included for research, preservation and interoperability. The MIT license in the
repository root does not apply to it.

The game's assets (graphics, sound, levels, text) are not included here: building the game needs your own
copy of `Diamondrush.jar`.
